# Product brief: Ajaia Docs

A **lightweight** document editor for small teams. This file demonstrates *Markdown import*.

## Goals

- Create, edit and share documents
- Keep formatting when a document is reopened
- Import existing `.txt` and `.md` notes

## Launch checklist

1. Seed demo users
2. Deploy to production
3. Record the walkthrough

> Scope note: real-time collaboration is intentionally out of scope.

Learn more at [the project README](https://github.com).
